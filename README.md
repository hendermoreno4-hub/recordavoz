# Recordá Voz

App de Android para anotar recordatorios hablando y recibir un aviso cada cierto tiempo.

## Descargar la app
Entra a la sección **Releases** de este repositorio y toca `RecordaVoz.apk`.

Cada vez que se suben cambios a `main`, GitHub compila una nueva versión sola (pestaña **Actions**, tarda unos 4 minutos).

## Qué hace
- Le dices "recuérdame tomar agua cada 2 horas" y guarda la tarea con su intervalo.
- Avisa con notificación, vibración y voz aunque la app esté cerrada o el teléfono bloqueado.
- Horario de "no molestar".
- Vuelve a programar todo si el teléfono se reinicia.
- Todo se guarda solo en el teléfono.
